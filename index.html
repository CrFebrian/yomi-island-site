Mode otomatis

Mode rapat : saat mikrofon dipakai, pengingat dan bunyi ditahan, dan yomi menjadi indikator rapat dengan jumlah yang ditahan.

Mode nonton : saat ada aplikasi layar penuh, seperti video atau game, island bersembunyi dan pengingat ikut ditahan.

Pasang Yomi Island dalam tiga langkah

Gratis untuk pemakaian pribadi.

  1. 1

    Unduh

    Tekan tombol di bawah. Berkas installer Yomi-Island-setup.exe langsung terunduh.

    Unduh untuk Windows
  2. 2

    Pasang

    Jalankan installer-nya. Windows mungkin menampilkan "Windows protected your PC" karena aplikasi ini belum bertanda tangan digital.

    Catatan SmartScreen

    Pilih Informasi lebih lanjut, lalu Tetap jalankan. Peringatan ini wajar untuk aplikasi yang belum bertanda tangan digital, tapi artinya Windows tidak bisa memverifikasi penerbitnya. Unduh hanya dari situs resmi ini.

  3. 3

    Selesai

    Yomi muncul di tengah atas layar. Klik untuk membuka, seret untuk menggeser. Yomi Island juga terbuka sendiri setiap Windows dinyalakan.

Pertanyaan yang sering muncul

Jawabannya singkat dan jujur, termasuk soal hal yang belum ada.

Apakah gratis?

Ya, untuk pemakaian pribadi non-komersial. Lisensinya source-available, bukan open source: kode boleh dibaca, tapi tidak boleh dijual atau dibagikan ulang tanpa izin. Baca LICENSE.txt.

Kenapa ada peringatan SmartScreen?

Installer belum bertanda tangan digital, jadi Windows menampilkan "Windows protected your PC". Pilih Informasi lebih lanjut, lalu Tetap jalankan. Unduh hanya dari situs resmi ini.

Data apa yang dikirim keluar?

Tidak ada akun dan tidak ada telemetri. Aplikasi hanya menghubungi AniList (jadwal anime), MangaDex (bab manga), LRCLIB (lirik, bila dinyalakan), dan GitHub (cek versi, bisa dimatikan). Rinciannya ada di Kebijakan Privasi.

Di mana data disimpan?

Lokal di laptopmu: task, buku, dan pengaturan. Catatan error ditulis ke error.log di folder data aplikasi, dan tidak dikirim ke mana pun kecuali kamu sendiri melaporkan masalah.

Bagaimana volume bekerja?

Tombol volume mengatur volume utama Windows, bukan volume satu aplikasi saja.

Musik atau lirik tidak muncul?

Pemutarnya harus melaporkan lagu ke Windows. Spotify, pemutar musik, dan browser biasanya bisa. Lirik bergantung pada ketersediaannya di LRCLIB.

Yomi hilang saat saya menonton?

Itu Mode nonton. Kamu bisa mematikannya di Pengaturan, bagian Mode fokus.

Pengingat tidak berbunyi saat rapat?

Itu Mode rapat, yang menahan pengingat dan bunyi saat mikrofon dipakai. Matikan di Pengaturan bila tidak mau.

Bagaimana cara menerima pembaruan?

Pengaturan, Umum, Pembaruan memeriksa GitHub Releases paling sering 12 jam sekali dan memberi tahu lewat yomi. Pemasangannya masih manual. Pembaruan otomatis bertanda tangan ada di rencana.

Bisa jalan otomatis saat Windows mulai?

Ya, dan itu otomatis: setelah terpasang, Yomi Island terbuka sendiri setiap Windows dinyalakan, tanpa pengaturan khusus. Tombol Keluar hanya menutupnya untuk sesi itu. Untuk menghentikannya selamanya, matikan di Pengaturan Windows, Aplikasi, Startup, atau copot pemasangan.

Bagaimana melaporkan masalah?

Buka Pengaturan, lalu "Ada masalah?". Itu membuka folder log dan formulir GitHub yang sudah terisi sebagian. Kamu meninjau isinya sebelum mengirim.

Bagaimana cara mencopot?

Pengaturan Windows, Aplikasi, lalu Yomi Island.

Bisa dipakai di Mac atau Linux?

Belum. Yomi Island hanya untuk Windows 10 dan 11.

Suka dengan Yomi Island?

Aplikasi ini dibuat sendirian, di sela-sela membaca manga dan menyelesaikan task. Kalau neko ini menemanimu dengan baik dan kamu ingin membalasnya, kamu bisa mentraktir lewat Saweria. Tidak ada kewajiban, dan semua fiturnya tetap sama.
