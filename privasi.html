Kebijakan Privasi Yomi Island

Berlaku sejak 10 November 2026. English version

Yomi Island berjalan di laptopmu. Aplikasi ini tidak memiliki akun, iklan, atau telemetri, dan pembuatnya tidak menerima data pribadimu.

Yang diproses di laptopmu

  • Pemutar media: judul, artis, sampul album, dan status putar dibaca dari kontrol media Windows untuk ditampilkan di pill dan tab Musik.
  • Suara latar: lagu lo-fi disertakan di dalam aplikasi dan diputar dari laptopmu, tanpa internet.
  • Jalankan saat Windows mulai: setelah pemasangan, aplikasi menulis satu entri startup di registri pengguna (HKCU\Software\Microsoft\Windows\CurrentVersion\Run) agar terbuka sendiri. Kamu bisa mematikannya di Pengaturan Windows, Aplikasi, Startup.
  • Volume utama, baterai, dan layar penuh: dibaca dari Windows untuk kontrol volume, indikator baterai, dan Mode nonton.
  • Status mikrofon: dibaca dari pengaturan privasi Windows hanya untuk mengetahui apakah ada aplikasi yang sedang memakai mikrofon, supaya Mode rapat bisa menahan pengingat. Yomi Island tidak merekam suara.
  • Task, buku, statistik baca, daftar anime dan manga, serta pengaturan: disimpan di database lokal di laptopmu.
  • Catatan error: ditulis ke berkas error.log di folder data aplikasi dan tidak dikirim otomatis ke mana pun.

Yang dikirim ke layanan lain

Hanya saat fitur terkait dipakai:

  • AniList (graphql.anilist.co): judul atau ID anime di daftarmu, untuk mengambil jadwal tayang episode.
  • MangaDex (api.mangadex.org): judul atau ID manga di daftarmu, untuk mengambil bab terbaru. Dicek tiap 30 menit selama aplikasi berjalan.
  • LRCLIB (lrclib.net): judul, artis, dan durasi lagu yang diputar, untuk mencari lirik. Hanya bila Lirik berjalan kamu nyalakan.
  • GitHub (api.github.com): permintaan biasa untuk memeriksa versi baru, paling sering 12 jam sekali, tanpa data pribadi. Bisa dimatikan di Pengaturan lewat "Beri tahu saat ada versi baru".

Layanan-layanan itu bisa melihat alamat IP-mu saat dihubungi, sesuai kebijakan mereka masing-masing.

Melaporkan masalah

Di Pengaturan, "Ada masalah?" membuka folder log dan formulir laporan GitHub yang sudah terisi sebagian (versi aplikasi, versi Windows, dan baris terakhir catatan error). Kamu meninjau isinya sebelum mengirim. Halaman GitHub Issues bersifat publik, jadi jangan menulis data pribadi di sana.

Situs ini

Situs ini tidak memakai analitik dan tidak memasang cookie. Saat dibuka, browser memuat font Zen Maru Gothic dari Google Fonts, sehingga Google bisa melihat alamat IP-mu. Tombol Unduh mengunduh installer langsung dari situs ini. Animasi pembuka memakai sessionStorage di browsermu hanya untuk mengingat bahwa animasi itu sudah tampil, dan data itu tidak dikirim ke mana pun. Situs ini dihosting di GitHub Pages, yang dapat mencatat kunjungan sesuai kebijakan GitHub.

Mengatur dan menghapus data

Matikan Lirik berjalan atau pemberitahuan versi baru kapan saja di Pengaturan. Data lokal ada di folder data aplikasi di laptopmu, dan kamu bisa menghapus folder itu sendiri. Untuk mencopot aplikasi, buka Pengaturan Windows, Aplikasi, lalu Yomi Island.

Kontak

Ada pertanyaan? Tulis di halaman Issues Yomi Island. Halaman itu publik, jadi jangan menulis data pribadi di sana.

Yomi Island Privacy Policy

Effective November 10, 2026. Versi Bahasa Indonesia

Yomi Island runs on your PC. It has no accounts, ads, or telemetry, and its developer does not receive your personal data.

Processed on your PC

  • Media player: title, artist, album cover, and playback state are read from Windows media controls to show in the pill and the Music tab.
  • Background sound: lo-fi songs are bundled inside the app and play from your PC, with no internet.
  • Run at Windows startup: after installation, the app writes one startup entry in the user registry (HKCU\Software\Microsoft\Windows\CurrentVersion\Run) so it opens by itself. You can turn it off in Windows Settings, Apps, Startup.
  • Master volume, battery, and full screen: read from Windows for the volume control, the battery indicator, and Watch mode.
  • Microphone status: read from Windows privacy settings only to tell whether any app is using the microphone, so Meeting mode can hold reminders. Yomi Island does not record audio.
  • Tasks, books, reading stats, anime and manga lists, and settings: stored in a local database on your PC.
  • Error log: written to error.log in the app data folder and never sent automatically.

Sent to other services

Only when the related feature is used:

  • AniList (graphql.anilist.co): the title or ID of anime on your list, to get episode air times.
  • MangaDex (api.mangadex.org): the title or ID of manga on your list, to get the latest chapters. Checked every 30 minutes while the app runs.
  • LRCLIB (lrclib.net): the title, artist, and length of the song playing, to find lyrics. Only if you turn on Synced lyrics.
  • GitHub (api.github.com): an ordinary request to check for a new version, at most every 12 hours, with no personal data. You can turn it off in Settings under "Notify me about new versions".

These services can see your IP address when contacted, under their own policies.

Reporting a problem

In Settings, "Having a problem?" opens the log folder and a partly filled GitHub report form (app version, Windows version, and the last lines of the error log). You review it before sending. GitHub Issues is public, so do not include personal data there.

This website

This website uses no analytics and sets no cookies. When it loads, your browser fetches the Zen Maru Gothic font from Google Fonts, so Google can see your IP address. The Download button fetches the installer directly from this site. The intro animation uses sessionStorage in your browser only to remember that it has played, and that value is never sent anywhere. The site is hosted on GitHub Pages, which may log visits under GitHub's policies.

Controlling and deleting data

Turn off Synced lyrics or new-version notices at any time in Settings. Local data lives in the app data folder on your PC, and you can delete that folder yourself. To uninstall, open Windows Settings, Apps, then Yomi Island.

Contact

Questions? Write on the Yomi Island Issues page. That page is public, so do not include personal data there.
